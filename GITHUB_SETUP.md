# GitHub setup guide

## Recommended repository

**Name:** `pneumatic-morphing-wheel`

**Description:** `Design exploration of a pneumatic morphing wheel for adaptive mobility, developed with the SKKU Soft Robotics Laboratory.`

**Suggested topics:**
`soft-robotics`, `mechanical-design`, `pneumatics`, `adaptive-mobility`, `cad`, `morphing-structures`

## Before making it public

Start the repository as **Private** unless you have already confirmed that the laboratory-generated CAD and photographs may be shared publicly. Also review `THIRD_PARTY_ASSETS.md` because the report contains externally sourced figures.

## Upload through the GitHub website

1. On GitHub, click **New repository**.
2. Name it `pneumatic-morphing-wheel`.
3. Paste the description above.
4. Choose **Private** initially.
5. Create the repository.
6. Unzip the prepared repository package on your computer.
7. In GitHub, choose **Add file → Upload files**.
8. Drag the **contents of the unzipped folder** into GitHub. Do not upload the ZIP itself as the repository contents.
9. Use a first commit message such as `Initial project portfolio`.
10. Open `README.md` on GitHub and confirm that both prototype images and the PDF report link render correctly.

## What visitors should see first

The root `README.md` is intentionally short and visual. The PDF report contains the detailed design narrative. CAD files are supporting artifacts. Exploratory raw spreadsheets are intentionally omitted from the public-facing version.

## If you want the report editable on GitHub

Keep `report/main.tex` and the `report/figures/` folder in the repository. These are the same files used for the Overleaf project. The compiled PDF should also stay in `report/` because GitHub can preview it directly.
