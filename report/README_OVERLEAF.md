# Overleaf instructions

1. Upload this entire folder (or the provided ZIP) to Overleaf.
2. Set `main.tex` as the main document.
3. Compile with pdfLaTeX.
4. For the cover, upload the **exact SKKU logo/signature image you provided** as:
   `figures/skku_logo.png`

The source intentionally does **not** recreate or approximate the SKKU logo. If `skku_logo.png` is absent, the cover falls back to plain university text so the document never displays an incorrect mark.

All six visual figures from the original report are preserved in `figures/` and are used in the revised report.
